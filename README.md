# Projeto-Personal-Kids

## 🏊 Sistema de Gerenciamento de Aulas de Natação

Projeto-Personal-Kids é um sistema completo para gerenciamento de aulas de natação voltado para crianças. Ele simplifica o agendamento de aulas, facilita a reposição de aulas perdidas e oferece um controle eficiente do vencimento de pagamentos. O sistema foi projetado para auxiliar administradores e professores na organização diária das aulas e no acompanhamento detalhado da frequência e situação financeira dos alunos.

---

## 🚀 Funcionalidades Principais

* **✅ Agendamento de Aulas:** Cadastro e visualização intuitiva de todas as aulas programadas.
* **✅ Gestão de Reposição:** Administração e reagendamento eficiente de aulas perdidas.
* **✅ Controle de Pagamentos:** Monitoramento proativo dos vencimentos das mensalidades.
* **✅ Relatórios e Monitoramento:** Visão detalhada da presença dos alunos e de sua situação financeira.

---

## 🛠️ Tecnologias Utilizadas

Este projeto é construído com as seguintes tecnologias:

* **Frontend:** **React** (Framework JavaScript)
* **Backend:** **Django** (Framework Python)
* **Banco de Dados:** **MongoDB**

## ⚙️ Como Rodar o Projeto (Instalação e Configuração)

Para configurar e rodar o Projeto-Personal-Kids em sua máquina, siga os passos abaixo para o **Backend** e o **Frontend** separadamente.

### ➡️ Configuração e Execução do Backend

1.  **Acesse a pasta do backend:**
    ```bash
    cd backend/
    ```
2.  **Crie o ambiente virtual:**
    ```bash
    python -m venv venv
    ```
3.  **Ative o ambiente virtual:**
    * No Windows:
        ```bash
        source venv/Scripts/activate
        ```
    * No macOS/Linux:
        ```bash
        source venv/bin/activate
        ```
4.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```
5.  **Rode o servidor:**
    ```bash
    python manage.py runserver
    ```
    O backend estará rodando, geralmente em `http://127.0.0.1:8000/`.

### ➡️ Configuração e Execução do Frontend

1.  **Acesse a pasta do frontend:**
    ```bash
    cd frontend/
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    ```
    Este comando instalará a pasta `node_modules` com todas as dependências do projeto.
3.  **Rode o servidor local:**
    ```bash
    npm run dev
    ```
4.  **Acesse no navegador:**
    Copie o link informado no terminal (geralmente algo como `http://localhost:5173/` ou similar) e cole no seu navegador para acessar a aplicação.
